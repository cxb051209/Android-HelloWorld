# 实验1 Android开发基础
福建师范大学 Android开发实验，第一个Android HelloWorld工程，完成环境搭建并同步到Git仓库。

## 开发环境
- Android Studio：Quail 4 (2026.1.4)，硬件不足可使用旧版本
- Git：版本控制工具
- 支持系统：Windows / macOS / Linux

> 新建项目会自动下载依赖库，需要保持网络通畅。Android Studio版本越高对电脑硬件要求越高。

## 实验任务
1. 安装Android Studio开发环境，阅读课程博客与Android官方开发文档。
2. 注册GitHub账号，本地安装Git工具。
3. 创建第一个Android HelloWorld工程。
4. 将项目推送至GitHub/Gitee，使用Android官方.gitignore过滤本地配置文件。
